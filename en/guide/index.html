    Generated Projects Guide¶

    Comprehensive guide for developing, testing and deploying projects created with create-go-starter

    Overview¶

    This comprehensive guide walks you through all phases of developing a project created with create-go-starter. Whether you're just getting started or looking for in-depth references, you'll find all the documentation you need here.

    Generated projects follow hexagonal architecture (Ports & Adapters) and incorporate Go development best practices.

    Recommended Learning Path¶

    Beginner¶

    If you're discovering create-go-starter, follow this path:

    1. circle Configuration - Initial setup
    2. circle Project Structure - Understand the organization
    3. circle Architecture - Hexagonal principles
    4. circle Practical Examples - Create your first entity
    5. circle API Reference - Test the API

    Intermediate¶

    To deepen your knowledge:

    1. circle Development - Advanced workflow
    2. circle Tests - Testing strategies
    3. circle Database - Mastering GORM
    4. circle Security - Best practices

    Advanced¶

    For production deployment:

    1. circle Deployment - Docker, K8s, CI/CD
    2. circle Monitoring - Observability
    3. circle Best Practices - Advanced patterns
